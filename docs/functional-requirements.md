# 機能要件定義書

## 1. アプリケーション概要
### 1.1 アプリケーションの目的
本アプリケーションは、将棋の棋譜を管理・検索するためのiOSアプリケーションです。
主な目的は以下の通りです：
- 局面検索機能を備えた使いやすい棋譜管理システムの提供
- 外出先での定跡確認の利便性向上
- 効率的な棋譜データベースの構築と活用

### 1.2 ターゲットユーザー
- 将棋プレイヤー（アマチュア）
- 将棋指導者
利用シーン：
- 外出先での棋譜確認
- 研究内容の記録・参照
- 類似局面の検索・研究
- 対局した棋譜の内容を登録・保存

### 1.3 システム構成
MVPはオンデバイス完結の単体アプリ構成とし、サーバサイドは持ちません。主な技術スタックはSwiftUI（UI）、SwiftShogi（将棋ロジック）、SwiftData（永続化）です。詳細は [`architecture.md`](./architecture.md) および [`basic-design-ios.md`](./basic-design-ios.md) を参照してください。

## 2. 機能要件
### 2.1 必須機能（MVP）
| 機能ID | 機能名 | 機能概要 | 優先度 |
|--------|--------|----------|---------|
| F001   | 棋譜入力 | ・UI操作による棋譜入力<br>・特定局面へのコメント付与<br>・特定局面へのタイトル付与<br>・任意の手数へのジャンプ<br>・局面の分岐作成 | 高 |
| F002   | 棋譜保存 | ・タイトルを付けての棋譜保存<br>・コメントと局面タイトルの保存<br>・保存データの検索 | 高 |
| F003   | 棋譜再生 | ・1手ずつの再生<br>・10手飛ばしの再生<br>・自動再生機能<br>・自動再生の一時停止 | 高 |
| F004   | 局面検索 | ・完全一致検索<br>・範囲指定による部分一致検索<br>・範囲指定による任意位置検索 | 高 |
| F005   | 将棋盤UI表示 | ・将棋盤の9×9マス目表示<br>・駒の配置表示<br>・現在の局面状態表示<br>・先手後手の区別表示 | 高 |
| F006   | 将棋盤駒操作 | ・駒のタップ選択機能<br>・移動可能位置のハイライト表示<br>・タップによる駒移動<br>・不正手のエラー表示 | 高 |
| F007   | 棋譜記録・管理 | ・操作した手順の自動記録<br>・棋譜の一時保存<br>・手の取り消し機能<br>・棋譜の永続化保存 | 高 |
| F008   | 局面注釈機能 | ・局面へのコメント付与・編集・削除<br>・局面へのタイトル付与・編集・削除<br>・タイトルによる局面検索<br>・検索結果からの直接局面表示 | 高 |
