# プロダクト概要

## KifuManagerとは
将棋の棋譜を管理・検索するためのiOS（SwiftUI）アプリケーション。局面検索を備えた棋譜データベースを端末上に構築し、「持ち歩ける研究ノート」として使えることを目指す。

- 局面検索機能を備えた使いやすい棋譜管理システムの提供
- 外出先での定跡確認の利便性向上
- 効率的な棋譜データベースの構築と活用

## 対象ユーザー
- 将棋プレイヤー（アマチュア）
- 将棋指導者

利用シーン:
- 外出先での棋譜・定跡の確認
- 研究内容の記録・参照
- 類似局面の検索・研究
- 対局した棋譜の登録・保存

## 主要機能（MVP）
| 機能ID | 機能名 | 概要 |
|---|---|---|
| F001 | 棋譜入力 | 盤面操作による手順入力、コメント・タイトル付与、任意手数へのジャンプ、分岐作成 |
| F002 | 棋譜保存 | タイトル付き保存、注釈の保存、保存データの検索 |
| F003 | 棋譜再生 | 1手送り・10手送り、自動再生と一時停止 |
| F004 | 局面検索 | 完全一致、範囲指定による部分一致・任意位置検索 |
| F005 | 将棋盤UI表示 | 9×9の盤面と駒配置、手番の表示 |
| F006 | 将棋盤駒操作 | 駒の選択、移動可能位置のハイライト、不正手のエラー表示 |
| F007 | 棋譜記録・管理 | 手順の自動記録、一時保存、手の取り消し、永続化 |
| F008 | 局面注釈機能 | 局面へのコメント・タイトルの付与/編集/削除、タイトル検索 |

各機能の詳細は [`functional-requirements.md`](./functional-requirements.md)、実現方法は [`functional-specification.md`](./functional-specification.md) を参照。

## スコープ外（将来フェーズ）
- クラウド同期（F101）: 複数デバイス間でのデータ同期
- 棋譜共有（F102）: 他ユーザーとの棋譜共有

MVPはオフライン完結を前提とし、ネットワーク通信・ユーザー認証を伴う機能は後続フェーズで検討する。
