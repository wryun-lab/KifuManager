# 要件サマリ

機能（`feature/<slug>`ブランチ）ごとに、レビュアー向けの要件サマリをこのディレクトリに追加します。

- ファイル名は仕様スラッグと一致させます: `<feature-slug>.md`（例: `photo-albums.md`）。
- 詳細な受け入れ条件（EARS形式）は `.kiro/specs/<feature-slug>/requirements.md` に記載されているため、ここでは全文を複製せず、以下を短く要約します。
  - 背景・目的
  - スコープ（対象/対象外）
  - 受け入れ条件の要約
  - 詳細へのリンク: `../../.kiro/specs/<feature-slug>/requirements.md`

現時点では機能スペックがまだ無いため、サンプルファイルはありません。最初の `feature/<slug>` ブランチで `/kiro-spec-requirements` を実行したタイミングで、このディレクトリにも要約ファイルを追加してください。
